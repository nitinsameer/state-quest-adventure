## ✅ What Capacitor Sync Does

Running `npx cap sync android`:
1. ✅ Copies `dist/` to `android/app/src/main/assets/public/`
2. ✅ Creates `capacitor.config.json` (runtime config)
3. ✅ Creates `capacitor.plugins.json` (plugin registry)
4. ✅ Updates Android native files for plugins
5. ✅ Prepares plugin bridge code
6. ✅ Validates plugin compatibility
