# states.json — factual/source audit ledger
This ledger accompanies `states_final_audited.json`. The JSON schema was not changed. Source fields were deliberately NOT added to the dataset.
## Source hierarchy used
- Government of India / State or UT Government
- Census of India (especially C-16 language data)
- Constitution / Gazette / legislation for official-language/legal wording
- UNESCO World Heritage Centre
- Archaeological Survey of India (ASI)
- National/state wildlife and forest authorities
- Official museums/institutions
- Reputable academic/institutional sources
- Reputable secondary sources only where an authoritative source was unavailable

## Claim-level changes

**182 changed string fields** were identified between the prior production candidate and the audited file. Each changed field is mapped to the appropriate source class below. Exact unsupported numbers, rankings, prices, superlatives and disputed origin claims were softened or removed rather than retained without strong evidence.
