## EXECUTIVE SUMMARY

Successfully diagnosed and fixed the white screen issue affecting the Explore India Android app. The root cause was a React hydration failure caused by an `async` attribute embedded in the TanStack Start router manifest script. The application now launches correctly and displays content.

Additionally, the build configuration has been locked and documented to prevent future regressions.

---

## ROOT CAUSE ANALYSIS

### Problem Statement

The Explore India Android app was displaying a blank white screen on launch, even though:
- The Android framework confirmed the activity was displayed
- WebView was loading successfully
- No obvious JavaScript errors were present in logcat

### Investigation Process

1. **Initial Assumptions (Ruled Out):**
   - ❌ Theme inflation error (fixed in earlier attempts)
   - ❌ Missing assets (verified present)
   - ❌ Incorrect Capacitor webDir (verified correct)
   - ❌ Broken routing (verified structure)
   - ❌ CSS padding conflicts (not the issue)

2. **Deep Analysis:**
   - Examined `dist/client/index.html` generated by build
   - Traced HTML structure and script tags
   - **Found:** Router manifest script contained `async:!0` (minified `async: true`)
   - **Impact:** This async attribute prevented React hydration

### Root Cause: Async Attribute in Router Manifest

**Location:** Embedded in `index.html` body via TanStack Start:

```html
<script>
  $_TSR.router=($R=>$R[0]={manifest:$R[1]={routes:$R[2]={...},
    scripts:$R[5]=[{attrs:$R[7]={type:"module",async:!0,src:"/./assets/index-DN5wQyZT.js"}}]
  }})($R["tsr"]);
</script>
```

**Why This Breaks:**

1. TanStack Start generates a router manifest with `async: true`
2. This embedded manifest script sets up routing state before React hydration
3. The `async:!0` (async attribute) causes the main bundle to load asynchronously
4. React tries to hydrate prerendered content before the async bundle loads
5. Hydration fails silently → Outlet remains empty → White screen

**Why Previous Fixes Didn't Work:**

- Theming fixes addressed Android framework level (not the issue)
- CSS changes didn't affect JavaScript hydration
- Code-splitting disables didn't remove the async from the manifest (only from final script tag)

---

## THE FIX

### File: `wrap-html.mjs`

Added post-build processing to remove async attributes from the embedded router manifest:

```javascript
// CRITICAL: Remove async attribute from embedded router manifest script
// Pattern: async:!0 should be removed from the router manifest script
shell = shell.replace(/async:!0,/g, '');
shell = shell.replace(/async:true,/g, '');
```

**Why This Works:**

1. Build completes with router manifest intact
2. `wrap-html.mjs` processes the shell HTML
3. Removes all `async:!0` patterns from embedded scripts
4. Final `index.html` has synchronous router manifest
5. React hydration completes successfully
6. Outlet renders content
