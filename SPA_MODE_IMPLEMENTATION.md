## Configuration

### vite.config.ts

```typescript
import { defineConfig } from "@lovable.dev/vite-tanstack-config";

export default defineConfig({
  // Disable Nitro server for SPA-only build (no SSR/server functions)
  nitro: false,
  tanstackStart: {
    // Enable TanStack Start SPA mode with prerendering
    spa: {
      enabled: true,
      maskPath: '/',
      prerender: {
        enabled: true,
        outputPath: '/_shell.html',
        crawlLinks: false,
        retryCount: 0,
      },
    },
  },
  vite: {
    base: './',
    build: {
      ssrManifest: false,
      rollupOptions: {
        output: {
          manualChunks: undefined,
        },
      },
    },
  },
});
```

**Key Changes:**
- `nitro: false` — Disables Nitro server (no `.output/server`, no SSR)
- `spa.enabled: true` — Activates TanStack Start SPA mode
- `spa.prerender.enabled: true` — Generates `_shell.html` with root route prerendered
- `base: './'` — Relative paths for WebView

## Build Chain

```bash
npm run build
  ↓
vite build
  ├─ Client build: dist/client/ (Vite + TanStack Start client plugin)
  │   └─ Outputs: JS bundles, CSS, assets
  ├─ SSR build: dist/server/ (for prerendering)
  │   └─ Temporary—used only for SPA shell generation
  └─ Prerender step: [TanStack Start Plugin]
      ├─ Spins up SSR server from dist/server/
      ├─ Renders root route (/) to HTML
      ├─ Generates dist/client/_shell.html
      └─ Embeds TanStack Router manifest + scroll restoration script
```

## Technical Notes

### Why SPA Mode?

- **CDN-friendly:** Static files—no server runtime required
- **Faster deployment:** No Nitro build overhead
- **Simpler caching:** All assets immutable by hash
- **Better for mobile:** Capacitor loads from local filesystem, not HTTP
- **Hydration works:** TanStack Router hydrates from prerendered HTML on client

### Why Disable Nitro?

The `@lovable.dev/vite-tanstack-config` includes Nitro by default (for SSR). For a pure SPA:
- `nitro: false` stops Nitro build (no `.output/server`)
- Prevents "server.js not found" error during prerendering
- SPA prerendering still works—TanStack Start uses its own internal SSR for shell generation

### Why the Split: dist/client vs dist/server?

- **dist/client/** — Served to users (browser assets)
- **dist/server/** — Temporary, used during build for prerendering
- For Capacitor, only `dist/client/` is deployed to the device
